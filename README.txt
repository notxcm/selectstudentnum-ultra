抽学号 Ultra · 随机点名  —— 使用说明
====================================

一句话：这是一个【单文件、原生 Win32、全 UTF-8】的随机抽学号（点名）程序。
直接双击「抽学号Ultra.exe」即可使用，无需安装，拷到任何 Windows 10/11 电脑都能跑。


★ 核心特性
----------
1. 全程 UTF-8：所有界面文字、学号、配置文件、导出记录均为 UTF-8 编码，
   中文/英文/数字/混合学号都能正确显示与保存。
2. 学号来源三合一（全部手动输入，零依赖）：
   · 范围：如 1,50,1,0 表示 1~50、步长 1、不补零；1001,1020,1,4 表示 1001~1020 且补零到 4 位。
   · 手动添加：每行一个，可填任意文字/混合学号（如 2023001、A07）。
   · 排除：每行一个，这些号码永远抽不到（例如请假的同学）。
3. 滚动抽取动画：点「抽号」或按空格，大卡片会高速滚动“翻牌”，再缓动停下，
   配合清脆提示音，课堂氛围拉满。
4. 不重复抽取：抽过的学号自动移出奖池（可关），直到奖池抽空。
5. 一次抽取 N 个：右上角「一次抽取」填数字，可一口气抽多人。
6. 避免最近：设置“避免最近 K 个”，抽中的短期内不再出现，分布更均匀。
7. 历史记录：左侧列表按时间倒序记录每一次抽取（序号. 学号 时间），
   支持撤销上一次、清空记录。
8. 导出 CSV：把记录导出为 Excel 可直接打开的 UTF-8(带 BOM) 文件。
9. 设置直接平铺在界面中间：学号范围/手动添加/排除/动画时长/界面缩放/音效/不重复
   全部一目了然，改完点「应用设置」立即生效，无需弹窗。
10. 图片半透明背景：以指定的动漫截图做高清背景（轻微模糊 + 半透明白蒙版），
   界面文字保持黑白灰体系（无花哨配色），字体始终清晰。
   背景图与图标均已【嵌入 exe】——仍是单文件，拷到任何电脑即用。
11. 高 DPI 自适应：在 4K/高分屏上清晰不模糊。
12. 全屏模式：F11 一键全屏，适合投屏。
13. 自动保存：关闭时自动记住范围/排除/手动/设置/记录，下次打开原样恢复。
14. Surprise 惊喜：左侧「Surprise」按钮打开极简小窗填写数字（可空格填多个），
   旁边的「必选」复选框是主界面一级开关：打勾则每次点抽号优先命中榜内数字
   （按顺序，仍在奖池中的才抽），不打勾则完全正常抽取。必抽榜永久保存不销毁，
   开关与数字都自动保存，无需进弹窗即可开关。清空输入或点「清空」即取消。


★ 快速开始
----------
1. 双击「抽学号Ultra.exe」。
2. 默认奖池是 1~50。点击中间的大卡片（或按 空格 / 回车）即可抽取。
3. 想改学号？界面中间的设置面板直接编辑：
   - 学号范围：每行一个「起始,结束,步长,宽度」，例如：
       1,50,1,0
       1001,1020,1,4
   - 手动添加学号：每行一个（可为任意文字）。
   - 排除学号：每行一个，这些号码不会被抽到。
   - 动画时长(毫秒)、界面缩放、开启音效、默认不重复。
   填完点「应用设置」立即生效。
4. 点「重置奖池」把所有学号放回奖池重新抽。
5. （作者小福利）左侧「Surprise」：填入幸运数字，勾选旁边的「必选」复选框后
   抽取时优先命中（永久保存不销毁）；不勾选则一切照常。


★ 快捷键
--------
空格 / 回车  ：抽取（焦点不在输入框时）
R           ：重置奖池
F / Esc     ：切换全屏
（重置、撤销、必抽榜、导出、清空记录、全屏用左侧按钮）


★ 文件说明（本程序目录）
------------------------
抽学号Ultra.exe        —— 主程序（单文件，拷贝即用）
抽学号Ultra.state.txt  —— 自动保存的当前状态（配置+记录），可删除恢复默认
README.txt             —— 本说明
示例配置.txt           —— 配置格式示例，供参考
src\                   —— 完整源代码（main.cpp / app.rc / 等资源），可二次修改


★ 兼容性 / 便携性
----------------
· 单个 exe，静态链接，不依赖任何第三方运行库；仅使用 Windows 系统自带 DLL。
· 目标系统：Windows 10 / Windows 11（多数“其他电脑”均满足）。
· 因为是原生 Win32 程序（非网页/电子壳），打开速度快、占用极小、极稳定。


★ 开发者：自行重新编译
----------------------
需要 MinGW-w64（gcc/g++/windres）。在项目 src 目录执行：
  g++.exe -std=c++17 -O2 -mwindows -static -static-libgcc -static-libstdc++ \
    -o 抽学号Ultra.exe main.cpp app.rc -lcomctl32 -lcomdlg32 -lwinmm -lshell32 -lgdiplus -lole32
（注意：链接器输出路径不要包含空格；若含空格请先输出到无空格临时目录再复制。）
逻辑层带单元测试：加 -DUNIT_TEST -mconsole 编译后可运行自检。
